# deploy-wise
Deploy wise is a web application which will help to know the availability of the Env across the teams/verticals for deployment.

# DeployWise (Phase 1 POC)

Monorepo scaffold for the Environment Reservation Phase 1 POC.

Quick start (you must have a PostgreSQL instance and set DATABASE_URL):

1. Install dependencies from the repo root: `npm install`
2. From root start API: `npm run dev:api`
3. From root start web: `npm run dev:web`

See each app's README for details.
